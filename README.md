# Marksmen Building & Design

Branding website for Marksmen Building & Design: custom woodworking, architectural millwork, and fine building.

Static site with no build step. Open `index.html` locally, or serve the folder from any static host (GitHub Pages works as is).

- `index.html`: page content
- `styles.css`: brand styles (navy, gold, cream; Cinzel + Cormorant Garamond)
- `script.js`: mobile nav, portfolio filters, lightbox, inquiry form
- `assets/img/`: web-sized project photos and crest

The inquiry form opens the visitor's email app addressed to the `data-email` value on the form in `index.html`.
